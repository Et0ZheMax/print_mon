# Print Monitor

Настольная панель для контроля сетевых принтеров. Приложение показывает доступность
веб-интерфейса, IP-адрес, уровни расходных материалов по SNMP и автоматически
синхронизирует список очередей с Windows print-сервером.

## Возможности

- адаптивная сетка карточек для окон любого размера;
- двухэтапная проверка: доступность отображается сразу, а SNMP подгружается в фоне;
- быстрая проверка до 64 устройств выполняется одной параллельной волной;
- поддержка HTTP и HTTPS веб-интерфейсов;
- уровни тонера/чернил K, C, M и Y через Printer-MIB;
- поиск и фильтры по состоянию;
- сводка: всего, в сети, требуют внимания, не в сети;
- автоматическое обновление SNMP и синхронизация с print-сервером;
- управление списком принтеров и порогами прямо из приложения;
- безопасное сохранение настроек и восстановление размера окна.

## Быстрый запуск

Требуется Python 3.11 или новее. На Windows из каталога проекта:

```powershell
python -m pip install -e .
python .\run_prn_site_ping.py
```

`run_prn_site_ping.py` можно запустить прямо из исходников; editable-установка
добавляет зависимость PySNMP и консольную команду:

```powershell
prn-site-ping --config .\config\printers.txt
```

Для разработки рекомендуется отдельное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest
```

## Конфигурация принтеров

Формат файла простой: одно имя принтера в строке. Пустые строки и строки с `#`
игнорируются.

```text
# Первый этаж
PRN-101
PRN-102

# Второй этаж
PRN-201
```

Путь выбирается в следующем порядке:

1. аргумент `--config`;
2. переменная `PRN_SITE_PING_CONFIG`;
3. `config/printers.local.txt`;
4. `config/printers.txt`;
5. встроенный демонстрационный список.

## Параметры запуска

```powershell
prn-site-ping --help
```

- `--config PATH` — файл со списком принтеров;
- `--columns N` — максимальное число колонок карточек;
- `--timeout SECONDS` — общий таймаут проверки HTTP/HTTPS;
- `--print-server HOST` — Windows print-сервер, по умолчанию `dc02`;
- `--sync-interval N` — интервал синхронизации в секундах, `0` отключает её.

Настройки SNMP сохраняются через окно «Настройки». Служебные файлы находятся в
`%APPDATA%\prn-site-ping`:

- `settings.json` — параметры SNMP;
- `printer_manager.log` — журнал диагностики;
- `window_position.txt` — размер и положение окна.
